# Chat Area 视觉层级优化设计

## 问题

当前 ChatArea 中 AI 回复存在以下视觉问题：

1. **每个 assistant turn 都显示头像 + "Claude" 标签**，在 agent loop 场景下（连续多个 AI turn），造成"AI 在连续发消息"的断层感
2. **所有 turn 之间间距相同**（mb-6），无法区分"轮次边界"和"同一轮次内的步骤"

## 设计决策

### D1: 去掉 AI 头像和名字标签

**决策**：完全移除 TurnCard 中的紫色头像圆圈和 "Claude" 文字。

**原因**：
- 这是 1对1 的 agent 工作场景，不是群聊。用户消息（右对齐灰色气泡）和 AI 内容（左对齐无气泡 + Activity Tree）的视觉差异已足够区分角色
- 头像暗示"一个角色在对话"，去掉头像暗示"系统在执行并汇报"——后者更符合 agent 产品的心智模型
- 每次重复显示头像消耗注意力预算但不提供新信息

**参考**：Claude Code 完全不显示 AI 头像/名字，纯靠内容样式区分。

### D2: 连续 assistant turn 之间用小间距

**决策**：连续的 assistant turn 之间使用 `mb-2`（8px），而非当前的 `mb-6`（24px）。

**原因**：
- 格式塔接近性原则：距离近的元素被感知为一组。小间距让连续 AI 操作被感知为"一个连续工作流"而非"多条独立消息"
- 零间距会让不同步骤糊成一段，8px 保留节奏感——"同一个工作流的不同步骤"
- 直接影响用户心智模型：是"AI 发了 3 条消息"还是"AI 做了一件事分了 3 步"

### D3: 角色切换时保留大间距

**决策**：user → assistant 和 assistant → user 的切换点保留 `mb-6`（24px）。

**原因**：
- 用间距编码信息层级：大间距 = 轮次边界（语义断点），小间距 = 同一轮次内的步骤
- 用户快速滚动时，大间距是视觉锚点，帮助定位"我在哪里提了需求"和"AI 从哪里开始回应"
- 统一间距会迫使用户靠读内容判断轮次边界，认知成本更高

## 实现方案

### 改动文件

1. **TurnCard.tsx** — 移除头像 + "Claude" 标签的 JSX，移除 `pl-8` 左缩进（不再需要和头像对齐）
2. **ChatArea.tsx** — TurnRenderer 中根据前后 turn 类型动态决定间距：
   - 连续 assistant turn：`mb-2`
   - 角色切换（user↔assistant）：`mb-6`

### 视觉效果

```
[用户气泡 - 右对齐]
          ← mb-6（轮次边界）
> 1 Edit...
改好了。现在结尾是：...
          ← mb-2（同一工作流）
> 1 Edit...
改好了。还有要调整的吗？
          ← mb-6（轮次边界）
[用户气泡]
```
