# Chat Area 视觉层级优化设计

## 问题

ChatArea 存在以下视觉问题：

1. **用户气泡颜色饱和度过高**：`#10a37f` 深绿白字，视觉权重过大，抢 AI 回复的注意力
2. **消息间距统一且偏小**：所有 turn 之间 `mb-4`（16px），内容密集时视觉拥挤
3. **排版层级扁平**：标题和正文大小差异不够，扫读时难以抓到结构
4. **每个 assistant turn 都显示头像 + "Claude" 标签**：agent loop 场景下造成"AI 在连续发消息"的断层感

## 设计决策

### D1: 用户气泡改为低饱和度 teal 灰

**决策**：`#10a37f` 深绿白字 → `#d9e4e4` teal 灰 + 深色文字。

**原因**：
- 用户消息是"已读过的内容"，不应抢 AI 回复的注意力
- 使用与背景（`#f0f7f7`）同色系的 teal 灰，整体色彩更一体化
- 中性灰（如 `#e8e8ea`）和 teal 背景没有色彩关联，显得"外来"

### D2: 拉大消息间距

**决策**：turn 间距从 `mb-4`（16px）→ `mb-6`（24px）。

**原因**：
- 16px 在内容密集时视觉拥挤，24px 提供足够的呼吸感
- 不加分割线，纯靠间距分隔，保持界面简洁

### D3: 增强排版层级

**决策**：
- H1: `text-xl` → `text-[22px]`，`mt-4` → `mt-6`
- H2: 保持 `text-lg`，`mt-3` → `mt-5`
- H3: `text-base` → `text-[15px]`，`mt-3` → `mt-4`

**原因**：
- H3 原来和正文（14px）同大小，完全没有层级区分
- 标题上方间距加大，让标题"跳出来"，扫读时能快速抓到结构

### D4: 去掉 AI 头像和名字标签

**决策**：完全移除 TurnCard 中的紫色头像圆圈和 "Claude" 文字，移除 `pl-8` 缩进。

**原因**：
- 1对1 agent 工作场景，不是群聊。左右对齐 + 气泡样式差异已足够区分角色
- 头像暗示"一个角色在对话"，去掉暗示"系统在执行并汇报"——更符合 agent 产品心智模型
- 每次重复显示头像消耗注意力预算但不提供新信息

**参考**：Claude Code 完全不显示 AI 头像/名字。

### D5: 连续 assistant turn 用小间距，角色切换用大间距

**决策**：
- 连续 assistant turn：`mb-2`（8px）
- 角色切换（user↔assistant）：`mb-6`（24px）

**原因**：
- 格式塔接近性原则：小间距让连续 AI 操作被感知为"一个连续工作流"而非"多条独立消息"
- 大间距编码轮次边界，用户快速滚动时作为视觉锚点定位自己的发言
- 本质：用视觉结构编码语义结构，让用户不用读内容就能理解对话节奏

### D6: 保持用户右对齐 / AI 左对齐的布局

**决策**：保持当前左右分布，不改为全部左对齐。

**原因**：
- 左右分布是聊天产品的主流模式，用户认知成本最低
- `max-w-3xl`（768px）居中是成熟的内容宽度选择，两侧留白是功能性的（分隔 sidebar + 控制行宽）
- 768px 在 14px 字号下约 90-95 字符/行，已偏宽，不宜再加宽

**否决的方案**：
- 全部左对齐（Claude.ai 风格）：虽然最大化 AI 内容可读性，但在左右分布已是主流的情况下不必要
- 混合布局：增加复杂度但收益不明显

### D7: Activity Tree 去卡片化，轻量内联

**决策**：移除 Activity Section 的背景色、边框、圆角，改为轻量内联样式。

**原因**：
- Activity Tree 是"AI 工作的过程记录"，不是"AI 要传达的信息"，应在视觉上退到背景
- 卡片化（背景 + 边框）把它提升到和回复文本同等的视觉层级，不符合信息优先级
- 参考 Claude Code：activity 就是普通文字行 + chevron，完全融入内容流

**否决的方案**：
- 保留卡片但默认折叠：没有从根本上解决视觉权重问题
- 半透明弱化：折中但不彻底

## 改动文件

| 文件 | 改动 |
|------|------|
| `UserMessageBubble.tsx` | 气泡颜色 `#10a37f` → `#d9e4e4`，文字白色 → 深色 |
| `ChatArea.tsx` | TurnRenderer 动态间距；移除 pending indicator 头像 |
| `TurnCard.tsx` | 移除头像 + "Claude" 标签；移除 `pl-8` |
| `Markdown.tsx` | H1/H2/H3 字号和上间距调整 |

## 视觉效果

```

          ← mb-6（轮次边界）
> 1 Edit...
改好了。现在结尾是：...
          ← mb-2（同一工作流）
> 1 Edit...
改好了。还有要调整的吗？
          ← mb-6（轮次边界）
[用户气泡]
```
